# Identidade do aplicativo

## Decisão
O nome de exibição do aplicativo é `JrBaseCentral` e os ícones nativos usam a arte fornecida pelo projeto como base visual.

## Aplicação
- `app.json` define `expo.name` como `JrBaseCentral`.
- `App.js` usa `JrBaseCentral` também na tela nativa de validação.
- `assets/icon.png` e `assets/adaptive-icon.png` são versões PNG 1024x1024 da arte aprovada.
- O `slug` do Expo permanece `PhotoList` para evitar alteração desnecessária de identificação do projeto/EAS.
