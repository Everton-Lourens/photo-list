# Sessão 2026-08-25

## O que foi alterado
- Removida a exigência de permissões nativas para abrir o site.
- A URL válida agora é salva e usada diretamente como `source` do WebView.
- Mantido o WebView como navegador embutido sem controles de navegador, com JavaScript e DOM storage habilitados.
- Mantido o fluxo de download de fotos, mas a permissão de mídia ocorre somente quando o salvamento é solicitado.
- Atualizada a documentação e as regras de permissões para refletir o novo fluxo.

## Conhecimento consolidado
Para carregar um site estático no APK, a validação deve se limitar ao endereço HTTP/HTTPS; o conteúdo HTML, CSS e JavaScript deve ser renderizado diretamente pelo `react-native-webview`. Permissões nativas não devem bloquear essa etapa básica.
